# GUSS

> Accéder au [répertoire](https://github.com/samucapte/guss)

GUSS est un outil pour tester [Loch](https://github.com/samucapte/loch) en monitorant les communications faites sur le canal de debug. Les résultats sont enregistrés sur un fichier local.
Il permet de valider si le comportement de la base correspond à celui attendu en consultant par après les logs et les données lues.

Optionnellement, les données peuvent être téléversées en ligne pour monitorer à distance le test. La configuration du serveur requis est décrite [ici](https://github.com/SAMuCaptE/GUSS/blob/main/server/Dockerfile).

### Utilisation

GUSS est outil CLI. Ses options sont disponibles dans son [répertoire](https://github.com/samucapte/guss).
