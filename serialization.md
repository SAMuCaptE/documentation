# Serialization

> Accéder au [répertoire](https://github.com/samucapte/serialization)

Serialization est un répertoire de documentation dans lequel se retrouvent les schémas utilisés pour encoder l'information perçue par [Loch](https://github.com/samucapte/loch).

Le processus est fait par des [Protobufs](https://protobuf.dev/) mais place aussi les bits dans chaque octet au préalable.

### Compilation

Un script fourni par l'utilitaire `make` permet de compiler les protobufs en C et en Go. Comme décrit dans le répertoire, cette étape ne doit être faite qu'une fois.
